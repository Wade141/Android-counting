**这是一个新手个人开发和维护的项目。** 而且本人对kotlin还需深入学习，可能会出现意想不到的问题，但至少目前已经在个人设备的IQOO 12 PRO上稳定运行了两个月了，望轻喷

## 用途

- **记录日常支出**：填写金额、消费名称、分类和备注，也可以修改或删除已有记录。
- **了解钱花在哪里**：查看当月消费、历史账单，按日期、分类、金额等条件查找记录。
- **管理预算**：设置每月预算，查看剩余可用金额；也可以用专项预算单独管理某类支出。
- **减少重复输入**：开启通知记账后，尝试从微信、支付宝的付款通知中识别支出。
- **从截图记账**：选择付款截图，或从相册分享到“截图记账”，识别后核对并保存。
- **整理和备份账本**：自定义分类、设置分类关键词，导出账单或备份数据。

## 适配和相关信息

适用于 **Android 8.0 及以上**设备。

这是包含本地文字识别模型的完整安装包，不需要另外下载模型。想查看源码或自行构建，可以展开页面底部的“开发者说明”。

安装后，可以先设置本月预算和常用分类，再记录第一笔支出。手动记账可以直接使用；截图记账需要选择图片；通知记账则需要按应用提示，主动开启系统的通知访问权限。

自动识别的结果建议核对。手机的后台限制、通知内容变化或截图不清晰，都可能导致漏记或识别不准确；有疑问的记录可以手动补充和修改。

## 数据与隐私

- 账目保存在手机本地，不会自动同步到云端。
- 截图文字识别在设备上完成，无需把付款截图上传到识别服务。
- 通知访问权限用于通知记账，手动记账和截图记账不需要这项权限。
- 建议定期备份账本，换机或卸载前先导出数据，并妥善保管备份文件。

仓库中的示例数据经过脱敏处理，不包含个人真实账本或私人付款截图。

## 关于这个项目

这是个人项目，目前仍在完善中，或者说测试期还没过，总而言之是第一次搞这些。不同品牌手机上的通知接收、后台运行和截图识别效果可能存在差异，暂不能保证所有机型都表现一致。
